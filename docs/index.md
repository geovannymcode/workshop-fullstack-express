# Workshop Fullstack Express: NestJS + React en 4 horas

## Bienvenido al Taller

**Duración**: 4 horas
**Nivel**: Principiante (no se requiere experiencia previa con NestJS, React, ni deployment)
**Prerrequisitos**: Saber escribir código JavaScript básico, tener una computadora con internet

Este workshop no es un curso teórico. Vas a construir una aplicación real de principio a fin, vas a subirla a internet, y al terminar vas a tener una URL pública que puedes compartir con tu familia y mostrar en tu portafolio.

---

## ¿Qué vamos a construir?

Una aplicación de **Lista de Tareas (To-Do List)** con dos partes:

1. **Backend** (el cerebro): un API REST en NestJS que guarda y devuelve tareas.
2. **Frontend** (la cara visible): una interfaz en React donde el usuario ve, crea y marca tareas como completadas.

Al final del workshop, tu aplicación va a vivir en internet con dos URLs:

- Tu API: `https://mi-api-tareas.onrender.com`
- Tu app: `https://mi-app-tareas.vercel.app`

---

## El Problema que Resolvemos

La mayoría de tutoriales de programación enseñan UNA cosa aislada: "cómo hacer un componente en React", "cómo hacer un endpoint en NestJS", "cómo usar Git". Pero un proyecto real no es UNA cosa, es muchas cosas trabajando juntas.

Cuando un estudiante termina un curso de React, generalmente no sabe:

- Cómo conectar React con un backend que él mismo creó.
- Cómo subir su código a GitHub sin romper nada.
- Cómo configurar CORS cuando el frontend y el backend están en dominios diferentes.
- Cómo desplegar la aplicación para que cualquiera pueda usarla.
- Por qué en producción se rompen cosas que en local funcionan.

Este workshop ataca exactamente ese vacío.

## Stack Técnico

| Capa | Tecnología | Por qué la usamos |
|------|------------|-------------------|
| Frontend | React + Vite | Es el framework más popular del mercado laboral |
| Backend | NestJS | Estructura clara, TypeScript, usado en empresas reales |
| Lenguaje | TypeScript / JavaScript | Estándar de la industria |
| Control de versiones | Git + GitHub | Indispensable en cualquier trabajo de desarrollo |
| Deploy Backend | Render | Tiene capa gratuita y se conecta con GitHub |
| Deploy Frontend | Vercel | El mejor para React, capa gratuita generosa |

## Para Quién Es Este Workshop

Este workshop está diseñado para ti si:

- Eres estudiante de programación o desarrollo de software.
- Sabes escribir código JavaScript básico (variables, funciones, arrays).
- Nunca has desplegado una aplicación a internet.
- Quieres tener un proyecto real para mostrar en entrevistas.

No necesitas saber nada de NestJS ni de React antes de venir.
