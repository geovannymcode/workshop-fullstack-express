# Workshop Fullstack Express

Workshop práctico de 4 horas para estudiantes que quieren construir y desplegar su primera aplicación fullstack real usando NestJS + React.

## ¿Qué se construye?

Una aplicación de **Lista de Tareas (To-Do)** desplegada en producción, con:

- Backend en **NestJS** (Node.js + TypeScript) desplegado en **Render**.
- Frontend en **React + Vite** desplegado en **Vercel**.
- Control de versiones con **Git y GitHub**.

## Estructura del workshop

| Sesión | Tema | Duración |
|--------|------|----------|
| 0 | Antes de empezar (instalaciones) | 30 min (previo) |
| 1 | Setup y control de versiones con Git | 1 hora |
| 2 | Backend con NestJS | 1 hora |
| 3 | Frontend con React | 1 hora |
| 4 | Deployment a producción | 1 hora |
